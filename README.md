# AS241S5_AEJ_04-be
## API 01 - Speech-to-Text AI
Speech-to-Text AI es un servicio de inteligencia artificial que proporciona capacidades de transcripción en tiempo real, convirtiendo el lenguaje hablado en texto instantáneamente; admite una gran gama de formatos de archivos de audio y video, lo que garantiza una buena integración con diversas fuentes de medios, además de contar con un soporte multilingüe, admitiendo la transcripción en numerosos idiomas.

## API 02 - WhatsApp Number Validator
WhatsApp Number Validator es un servicio de verificación de números activos de la plataforma de WhatsApp, permitiendo así la verificación de los números de los clientes (en caso de empresas), mejorar las interraciones de los usuarios, etc.

## Herramientas utilizadas
- Java: JDK 17
- IDE: Visual Studio Code
- Maven: Apache Maven
- Frameworks: Spring WebFlux
- Database: MongoDB
- Rapidapi: Speech-to-Text AI | WhatsApp Number Validator
